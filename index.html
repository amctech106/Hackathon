Supabase Quick Cheat-Sheet (Kal ke liye)

1. Data Fetch Karna (SELECT)

Apni table ka saara data lene ke liye:

const { data, error } = await supabaseClient
  .from('your_table')
  .select('*')
  .order('created_at', { ascending: false });

2. Naya Data Daalna (INSERT)

Naya record insert karne ke liye:

const { data, error } = await supabaseClient
  .from('your_table')
  .insert([{ title: 'My Title', user_id: currentUser.id }]);

3. Data Update Karna (UPDATE)

Kisi specific ID ka data update karne ke liye:

const { data, error } = await supabaseClient
  .from('your_table')
  .update({ status: 'completed' })
  .eq('id', recordId);

4. Data Delete Karna (DELETE)

Kisi item ko delete karne ke liye:

const { error } = await supabaseClient
  .from('your_table')
  .delete()
  .eq('id', recordId);
