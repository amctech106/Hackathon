    Supabase Cheat Sheet

    Copy-paste these snippets during your hackathon to move fast.

    SELECT (Read)

    Fetch all rows from any table:

    const { data, error } = await supabaseClient
  .from('your_table')
  .select('*')
  .order('created_at', { ascending: false });

    INSERT (Create)

    Add a new row:

    const { data, error } = await supabaseClient
  .from('your_table')
  .insert([{ title: 'Hello', user_id: currentUser.id }]);

    UPDATE (Edit)

    Modify an existing row:

    const { data, error } = await supabaseClient
  .from('your_table')
  .update({ status: 'completed' })
  .eq('id', recordId);

    DELETE (Remove)

    Delete a specific row:

    const { error } = await supabaseClient
  .from('your_table')
  .delete()
  .eq('id', recordId);
